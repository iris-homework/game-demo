从 `sources.json` 记录的社区音轨页面下载，保留原始 MP3 字节；来源、下载地址、日期及 SHA256 见该文件。此下载来源不构成另一款游戏的使用或再分发许可，未核实开放授权；素材不随本工程代码许可证重新授权。

正式主场景由 `scripts/audio/background_music.gd` 持有单个播放器：全曲循环，默认 −12 dB，使用发送到 Master 的独立 Music 总线。设置中的「开启音乐」「音乐音量」即时控制音乐并自动保存，默认开启、100%；总音量仍统一控制音乐与音效，SFX 开关和音效音量不影响音乐。关闭音乐时静音并保留循环进度，再开启接着播放。所有非战斗页面连续播放，不随页面重建从头开始；进入正式战斗、战斗演练或新手教程立即停止，离开战斗、切至非战斗页面后从头播放。战斗中的确认层、牌堆和科技弹窗不恢复音乐。

退出游戏沿用统一音频收尾，停止播放器并清空其流引用；音乐偏好只保存到 `settings.cfg`，不写入冒险存档。
