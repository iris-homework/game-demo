# 增强战斗测试台

这是独立运行的背景、诺伦动作、敌人和卡牌测试工具。左侧通过**地图｜卡牌**
切换，右侧通过**noren｜敌人1｜敌人2｜敌人3**选择控制对象。

角色选择、战斗名称、目标与信息标签使用素材目录名，如`01a_warden_shield`、
`02b_robot`。主角为`noren`，`unillustrated`显示为“无立绘”；不更改正式游戏名称。
原有测试定义全部保留，共用素材的选项名称相同，悬停可查看内部敌人ID。

## 启动

在 Godot 编辑器打开
[battle_background_preview.tscn](battle_background_preview.tscn)，按 **F6**
运行当前场景，即可打开测试台。测试台不需要 `.bat` 或 `.cmd` 启动器。

自动验证保留 `launch.ps1`，用于定位引擎、隔离用户目录和保存检查日志。
它依次读取 `GODOT_PATH`、`tools/local_paths.json` 和 PATH 中的 Godot，
也支持传入 `-GodotPath` 指定引擎。

## 左侧地图与卡牌

**地图**提供11个已有专用战斗背景、缩放、水平／垂直偏移、地面分界、
亮度、饱和度、对比度、额外底部渐暗、脚底辅助线、全景／近景和截图。
内容超出面板时使用滚轮向下查看。原有战斗渐暗继续保留，滑块调整额外渐暗。
图像边缘会限制取景，放大背景后可获得更大的偏移范围。

**保存当前**仅把当前地点写入本目录的 `background_profiles.json`。
其他地点的未保存草稿继续保留在内存中。**恢复已存**读取当前窗口载入或保存
的参数，**恢复初始**采用正式背景的原始取景参数。关闭时若有地图草稿会提示。
参数重启后继续读取；不会改写正式资源配置。

**卡牌**支持按名字、编号或 ID 搜索全部40种诺伦卡。选择后点击加入，
或双击列表，可以直接加入当前真实手牌；同名卡可重复加入，上限20张。
支持移除所选、清空、记住当前手牌和恢复手牌。手牌列表及其下方操作也可以滚动。
**记住当前手牌**仅在本窗口保留；**重置本轮**也使用这套手牌。
底部的**补满能量／弹药**按当前规则补足资源；卡牌仍使用正式费用与效果。

## 右侧角色与动作

诺伦固定为主角，可以切换近战／远程形态。形态选择只设置当前测试形态，
不触发切换奖励；通过卡牌切换则正常执行正式规则。

每个敌人槽位可独立选择种类，最多三名、至少一名。增减或更换敌人会重置本轮，
双方恢复100 HP，地图参数保留。只有待机素材的敌人标注为**素材预览**，
仅提供待机姿势，攻击意图使用测试占位值，不代表正式敌人规则。
2026-10-24已删除芬恩占位形象；尚无专属图的敌人显示“无立绘”，保留目标选择、血条与意图，静态姿势列表为空。

**静态姿势**只列出当前对象已加载的素材，可以保持待机、移动、攻击、格挡、
受伤等画面。**完整演示**播放所选动作、适用的接近／特效与归位，支持目标选择、
单次、循环和暂停／继续，并可选择正常、半速或四分之一速。播放结束后恢复原时间倍率。
启用辅助线可同时查看选中动作的发射／接触点及目标命中点。
载入[制作台攻击模板](../../../enemy_asset_pipeline/README.md#攻击标签与演出模板)后，
右栏显示攻击类型、位置行为与姿势顺序；同角色的多个模板可分别完整演示。
完整演示只播放表现，不结算伤害或消耗战斗资源；
通过手牌出牌及结束回合则执行真实规则。结束演练后点击**重置本轮**继续。
脚底坐标可以微调角色站位；修改后的站位保留到本次视图重建。

## 快捷键与输出

你可以用快捷键收起控制栏，查看完整战场：

| 按键 | 行为 |
| --- | --- |
| `Tab` | 同时隐藏／显示两侧控制栏 |
| `[` | 单独隐藏／显示左栏 |
| `]` | 单独隐藏／显示右栏 |
| `Ctrl+S` | 保存当前地图参数 |

文本框输入期间保留常规编辑操作；数字不会选中战斗卡。
截图自动隐藏左右栏与快捷键提示，PNG和当时的地图／战斗参数JSON保存在
`tests/combat/workbench/captures/`。运行日志、隔离用户目录与自动验证输出位于 `tests/combat/workbench/runtime/`。
这两个目录已忽略Git跟踪。

## 验证与维护

运行自动检查时使用以下命令，实际结果写入 `runtime/qa/result.json`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\combat\workbench\launch.ps1 -Check
```

这套检查包含真实Godot渲染与程序注入的输入，不等同于物理鼠标游玩验收。
历史通过记录见[修改记录](../../../docs/修改记录.md)。

本目录脚本复用正式战斗视图、动作舞台和规则模型。测试入口关闭自动保存，
直接保存路径也指向测试专用文件；启动脚本进一步隔离 `APPDATA` 与
`LOCALAPPDATA`。不会向正式冒险或科技档案写入测试数据。
当前素材按编号整理后的路径由 `battle_background_preview_visuals.gd`
在进程内适配，只有待机的新素材按透明边界估算脚底与尺度，需要人工检查；
这些参数不作为正式资源接入的校准结果。
