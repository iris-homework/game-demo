## 2026-10-17 变异的鱼与污染

B11 为两只变异鱼，各30 HP。第一只循环「攻击6 → 攻击2×2 → 施加3层污染」，第二只循环「施加3层污染 → 攻击6 → 攻击2×2」。鱼的每段攻击实际穿透格挡造成伤害时，额外施加2层污染。每只鱼死亡时向角色施加3层污染，仅触发一次；同时击杀两只合计6层。污染为负面效果，上限999；持有者自身回合结束时受到等于层数的伤害（先扣格挡），再减1层。污染伤害不触发攻击追加污染或弹反。主菜单“敌人测试”也使用双鱼30 HP配置；已有战斗快照保留原配置；若已明确保存死亡污染5层，仍按5层结算，新开战斗使用3层。

变异鱼主动施加污染时会张嘴吐出绿色液滴，命中角色后显示绿色飞溅与挂滴，并同步显示污染层数；咬击实际造成伤害并附加污染时播放近距离溅射。完全格挡、死亡施加与回合末污染扣血不播放这套特效。鱼死亡时另播快速全身爆裂：身体瞬间散开，细小绿水滴以不同方向和速度喷散、快速下落消退，整段约0.48秒；死亡污染仍只施加一次。

场内血条保持原来的脚下位置，不避让立绘；立绘绘制在血条上方，重叠时可挡住血条。右上角每名敌人使用独立的信息块，仿照玩家顶部状态栏：名称在上，细长矩形血条在下，血量数字放在右侧，各块间留出间距。血量与格挡逐次命中同步更新，不随战场镜头移动。

## 2026-10-16 手牌选中与释放

战斗中可按 **1～9** 选中从左到右第1～9张手牌，**0** 选中第10张，小键盘数字同样可用。只选中不自动打出，仍用鼠标确认目标／出牌，右键或Esc取消；重复按同一键保持选中。出牌后按当前手牌顺序重新对应，缺少该序号时不操作。动画、转场和弹窗期间暂停快捷选牌，组合键不触发。

非攻击牌点选后持续跟随鼠标；在取消前，下一次左键点击优先用于出牌，即使点击其他手牌、科技、牌堆、结束回合或退出按钮，也不会触发对应按钮。自身／群体非攻击牌可在整个游戏画面内点击或拖放使用，不显示释放大框或“点击释放”提示。需要指定敌人的技能仍须点有效敌人，点其他位置只保留选中。首次原地选牌松手不出牌；右键或 Esc 明确取消后恢复普通按钮操作。攻击牌保持贴近底边、居中置顶及原目标规则；拆卸弹药需选择消耗另一张任意手牌，本牌自身进入弃牌堆。

`startingDeck` 是基础初始十张，`state.deck` 保存额外获得的牌；`removedStartingCards` 逐份记录已出售的基础牌。正式战斗、演练和牌库统一使用 `full_deck_ids()` 的实际拥有牌组，演练退出恢复原冒险。旧存档里的测试牌、旧待领奖励与进行中的战斗快照继续兼容。

## 战斗操作与本轮规则

战斗中隐藏顶部七天时间条及 WEEK 字样，其他页面仍显示日期。开场居中显示“第1回合”；结束玩家回合时显示“敌方回合”，剩余手牌同时飞入弃牌堆；提示结束后执行敌方行动，随后显示“第2回合／第3回合／第n回合”，再抽牌开放操作。己方回合提示采用亮蓝文字、电光蓝光晕与边框；敌方保持红色。[亮蓝配色预览](docs/预览/己方亮蓝回合/第1回合_亮蓝.png)。提示采用电子屏扫描线与错位闪烁，**从下往上出现，再从下往上消失**，单次约 1.1 秒。提示期间锁定操作，战败后不再播下一玩家回合。[动画时序预览（旧配色）](docs/预览/同步弃牌/敌方提示同步弃牌.gif)。

诺伦起始携带三项主动科技，点击左下角“激活科技”查看：**异次元口袋**（切换形态，冷却3回合）、**加速时钟**（弃置所有手牌，抽等量牌，冷却999回合）、**后备能源**（恢复1点能量，冷却3回合）。点击卡牌或按数字1—3激活，成功后自动回到战斗；冷却中的卡变灰并显示剩余回合。

冷却计入使用当回合，每进入下一玩家回合减少1；例如第1回合使用冷却3的科技，第4回合可再次激活。形态切换触发现有的切近战抽2／切远程攻击减费，能量可临时超过3。地图“牌库”左侧的“科技配置”可从已有科技中选择最多四项携带，也可全部卸下；空槽显示“空位”。点击携带或卸下后立即随本次冒险保存，无需手动保存；关闭或 Esc 返回地图并保留修改。角色的 `cyberwareIds` 决定起始拥有与默认携带，旧进行中战斗保留原科技，下场新战斗采用保存的携带配置。详情见[角色科技规则](docs/游戏规则.md#角色的战斗科技)与[开发接入说明](docs/开发接入说明.md#角色科技配置)。主菜单科技档案现为六项科技的两行三列只读图文展示；跨冒险获取与装备仍为预留。

1. 开场近战、2 颗弹药，洗牌后抽 5 张，每回合 3 能量，弹药上限 10。
2. 攻击牌选中后贴底居中置顶；非攻击牌选中后跟随鼠标并优先接管左键。自身／群体非攻击牌可在整个游戏画面内点击或拖放使用，指定敌人的牌仍需有效敌人；先用右键／Esc 取消，才能操作其他按钮。
3. 近战每实际攻击段回1弹；远程通常每张攻击耗1弹，本体通常乘1.5，弱点瞄准生效后乘2；切入斩先攻击再切近战，快速装填先补2弹再切远程。实际进入近战抽2，进入远程的下一张攻击减1费。完整状态结算见[卡牌说明](docs/诺伦卡牌与控制台.md)。
4. 拆卸弹药手动选择另一张手牌消耗，本牌自身弃置；火力倾泻自动耗尽全部弹药，终结弹只耗通常的1弹，均无额外耗弹选择。消耗牌与能力进入独立消耗区；逆刃架势进入普通弃牌区。
5. 结束回合弃置剩余手牌，敌人按意图攻击；下一回合清除玩家格挡、恢复 3 能量并抽 5 张。抽牌堆空时回收弃牌并洗牌。
6. 全部敌人 HP 归零获胜，玩家 HP 归零失败。B04使用15／15／30 HP黑帮，B11使用双鱼各30 HP正式配置；其他敌人仍有原型数值，整体难度尚未平衡。

2026-10-13 动作测试改为整次攻击收尾且卡牌飞抵弃牌堆后开放下一张牌；伤害飘字与入堆光环可继续收尾。致命攻击、回合切换和霓虹转场期间保持锁定。点击抽牌堆或弃牌堆打开大尺寸浏览界面：每行最多五张完整卡面，重复卡逐张保留，超出区域可用滚轮／触控板上下滚动。按卡牌配置默认顺序排列，同种卡聚合，展示顺序与实际抽取顺序无关。Esc、右键或返回按钮关闭。“调试结果”保留模拟胜利、失败入口；投降功能已移除。战斗页面不再显示道具栏及空槽。战斗中央的操作／状态提示文字已移除，包括选牌、锁定、攻击命中和手牌补充提示；伤害飘字、瞄准线与电子屏回合过场保留。

伤害数字采用亮白字芯、红色光晕、青红错位残影与碎片闪光，短促放大后上浮消散；连续命中错位显示，玩家受伤带 HP 标记。[动态预览](docs/预览/伤害数字/霓虹伤害预览.gif)。

抽牌动画动态预览：[霓虹抽牌](docs/预览/抽牌动画/抽牌动画预览.gif)。五张错峰发牌约 0.60 秒完成，落稳后即可操作，余光继续淡出。

弃牌动画动态预览：[霓虹弃牌](docs/预览/弃牌动画/弃牌动画预览.gif)。单张弃牌飞行约 0.40 秒；当前等待角色收势与入堆后解锁，致命攻击还需等待死亡淡出，再进入结算转场。

## 城市地图的素材边界

地图底图已优化放大采样与缩小过滤，提升建筑边缘清晰度；原图尺寸为 1671×941。

地图支持 **100%～150%** 缩放：滚轮或右下角 **−／＋** 调整，点击百分比恢复全图。放大后按住鼠标左键上下左右拖动，地图边缘限制移动范围；最小比例固定。地点标记和文字保持原大小，拖动不会误触地点详情。

城市总览当前由 `data/map.json` 的 `cityMapAssetId: city_map_expanded` 选择 `assets/map/map-expanded-v1.png`，原始 `map.jpg` 保留。`data/assets.json` 的 `mapContentRect` 指定扩绘图中的原城市区域，17 个地点的 `mapAnchor` 仍以该区域为坐标基准；地点符号复用 `assets/icons/map/`。科技教会默认开放，已接入专属地点背景，当前没有专属事件或服务。更换底图时应核对原城市区域和锚点映射，不能直接把旧锚点映射到整张扩绘图。

地点标记高 72 逻辑像素，配深色实底和清楚亮边。事件按关联战斗类型显示：普通为黄色感叹号，精英为红色感叹号，Boss 为彩色霓虹故障骷髅头，地点边框同步彩色故障。无战斗事件按普通；同类多个事件显示数量，混合类型分别显示，地点边框采用最高类型。当前位置保留 56 像素青色诺伦圆头像，无事件时地点标记为青色；当前已刷新事件统一决定目标与常驻名称。当前四场战斗仍全部普通。目标只取全局最多3项的刷新池，并校验真实条件，不使用委托对象 `targetId` 或上一次 `activeEventId` 作为目的地。

悬停时图标轻微提亮并平滑放大 6%，不叠加悬停外框或弹出简介卡；点击固定详情，再通过按钮进入地点、开始任务或治疗。空白或 Esc 关闭详情；详情可滚动并自动避开窗口边界，不改变底图位置。地图不制作小人行走，完整方向见 [美术方向](docs/美术方向.md)。

## 存档兼容与恢复

冒险检查点为 `user://checkpoint.json`，备份为 `.bak`。macOS 默认目录：`~/Library/Application Support/MidnightCommissionDemo/`。

冒险仍使用 schemaVersion 2；缺少 `playerCharacterId` 的旧档自动补 `noren`，不随默认角色设置改变。已有战斗快照不按新角色配置重建。R1 自动读取并迁移初版存档：保留仍有效的剧情、目标、信用点及领取记录，补充 HP 100、最大 HP 100、第 1 天和空战斗字段。写入仍采用临时文件替换及备用检查点。

每次出牌与结束回合保存 HP、意图、四个牌区、能量、形态、弹药、状态及能力。独立的开场发牌标记防止空手读档多抽牌，详见[维护文档](docs/维护文档.md)。演练不写入上述文件。正式战败进入独立战败页，本局结束，可返回主菜单开始新的委托；失败冒险不能继续或返回地图重试。零HP进入正式战斗也判负，演练仍保持隔离。

局外科技存档为同目录的 `meta_profile.json`，初始 `cyberwareState` 为空，当前不提供装备或属性效果。
