## 项目简介

《午夜委托》是一款使用 Godot 制作的赛博朋克回合制卡牌游戏。玩家扮演自由佣兵诺伦，在城市中承接委托，通过卡牌战斗获取奖励、扩充牌组，并挑战第一周的双人舞者 Boss。

- **卡牌战斗**：40 种诺伦卡牌，围绕近战／远程形态、弹药与状态效果组合策略。
- **城市探索**：地点委托、剧情选择、黑市交易、科技配置与诊所治疗。
- **战斗演练**：从主菜单直接体验不同敌人，退出后恢复原冒险进度。

## 快速开始

1. 使用 **Godot 4.7 标准版**导入本目录的 `project.godot`（Compatibility 渲染）。
2. 等待资源导入完成，按 **F5** 运行。
3. 在主菜单选择「新的委托」开始游戏，或选择「战斗演练」体验战斗。

macOS 安装 Godot 后，也可双击 `启动Demo.command` 启动。

Windows 可将 **Godot 4.7 标准版**解压后的 exe 放在本目录，然后双击 [`启动Demo.bat`](启动Demo.bat)。脚本会先导入资源再启动游戏，首次启动请耐心等待。也支持从 `PATH` 查找 `godot.exe`／`godot4.exe`，或通过 `GODOT_PATH` 环境变量指定 exe 完整路径（值不加引号）。需要保留完整工程文件，本脚本不包含 Godot 引擎。

## 基本操作

| 操作 | 方式 |
| --- | --- |
| 出牌 | 点击卡牌后点击有效目标，或拖至有效目标松开 |
| 快捷选牌 | 数字 **1～9** 选择对应手牌，**0** 选择第 10 张，再用鼠标确认 |
| 取消选牌 | 鼠标右键或 **Esc** |
| 结束回合 | 点击「结束回合」 |
| 查看牌堆 | 点击抽牌堆或弃牌堆 |
