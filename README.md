# 午夜委托 第一周 Godot Demo R1

本版根据《第一次修改清单》和更新后的实现文档，将原战斗占位页改为可实际出牌的临时战斗，并接入血量、七天时间、治疗、战斗转场与独立义体入口。正式卡牌和敌人数值仍未定稿，测试规则与正式内容分开存放。

## 立即体验

使用 **Godot 4.x 标准版**导入 `project.godot`，等待素材导入后按 **F5**。已在本机 Godot 4.7.2、Compatibility 渲染下验证。macOS 也可双击 `启动Demo.command`。

主菜单新增两个快捷入口，均不写入或覆盖冒险存档：

- **战斗演练**：后巷场景，敌方立绘缺失时保持透明空位，名称、HP 和意图仍显示。
- **机甲演练**：展示诺伦与复仇机甲的战斗立绘。蜂巢城寨背景仍缺失，明确显示待补提示。

正常剧情的所有战斗入口都已接入同一套战斗，不需要从演练进入。

## 战斗操作与本轮规则

战斗中隐藏顶部七天时间条及 WEEK 字样，其他页面仍显示日期。开场居中显示“第1回合”；结束玩家回合时显示“敌方回合”，剩余手牌同时飞入弃牌堆；提示结束后执行敌方行动，随后显示“第2回合／第3回合／第n回合”，再抽牌开放操作。己方回合提示采用亮蓝文字、电光蓝光晕与边框；敌方保持红色。[亮蓝配色预览](docs/预览/己方亮蓝回合/第1回合_亮蓝.png)。提示采用电子屏扫描线与错位闪烁，**从下往上出现，再从下往上消失**，单次约 1.1 秒。提示期间锁定操作，战败后不再播下一玩家回合。[动画时序预览（旧配色）](docs/预览/同步弃牌/敌方提示同步弃牌.gif)。

点击左下角“激活义体”，打开两行三列的六张紫色卡牌。名称暂用“临时义体 01—06”，效果均为下次攻击伤害 +1。点击卡牌或按数字 1—6 即可激活，卡面变灰并标记冷却中；Esc、右键或返回按钮关闭。

**每张义体冷却 1 回合，使用当回合计入冷却，下个玩家回合恢复可用；多张加成叠加。** 例如激活两张后，下一次临时攻击造成 3 点伤害，再下一次恢复 1 点。未使用的加成跨回合保留；无效目标与取消瞄准不消耗加成。当回合冷却状态与待生效加成随战斗存档保存，新战斗重置。名称、效果和次数限制均为原型规则，独立放在临时系统中，局外义体档案仍为预留入口。

1. 开场从左侧抽牌堆飞入五张临时攻击卡：青红霓虹拖尾、旋转弧线展开、落位描边；回合补牌使用同一效果。
2. 按下手牌立即选中并显示指向线，按住拖到敌方后松开出牌；也可先点选，再点击敌方出牌。弧形箭头跟随鼠标，指向有效敌人时变为洋红色并显示锁定环。再次点卡牌、右键或 Esc 取消。
3. 每张卡造成 **1 点伤害**，命中后以旋转弧线飞入右侧弃牌堆，附带青红霓虹拖尾、卡形残影与入堆光环。回合结束的剩余手牌错峰飞入。
4. 单个敌人初始 **3 HP**，头顶显示下一次行动 **攻击 1**；打出三次攻击即可自然获胜。
5. 点击“结束回合”，敌人按意图造成 **1 点伤害**，然后开始下一回合。
6. 玩家 **HP 归零**自然战败。投降、自然胜负与开发结果模拟均返回正确剧情节点。

当前测试牌不计算费用。为验证完整回合循环，临时配置采用“回合结束弃置剩余手牌、抽牌堆不足时回收弃牌堆、每回合补到五张”的规则；这些设置位于 `data/prototype/combat.json`，不是正式战斗定稿。

出牌起手的 0.16 秒内锁定重复操作，命中后即可继续选下一张牌，伤害飘字和弃牌飞行动画在后台收尾。致命攻击、回合切换和霓虹转场期间保持锁定。点击抽牌堆或弃牌堆打开大尺寸浏览界面：每行最多五张完整卡面，重复卡逐张保留，超出区域可用滚轮／触控板上下滚动。按卡牌配置默认顺序排列，同种卡聚合，展示顺序与实际抽取顺序无关。Esc、右键或返回按钮关闭。“调试结果”保留模拟胜利、失败入口；“投降”单独显示。战斗页面不再显示道具栏及空槽。战斗中央的操作／状态提示文字已移除，包括选牌、锁定、攻击命中和手牌补充提示；伤害飘字、瞄准线与电子屏回合过场保留。

伤害数字采用亮白字芯、红色光晕、青红错位残影与碎片闪光，短促放大后上浮消散；连续命中错位显示，玩家受伤带 HP 标记。[动态预览](docs/预览/伤害数字/霓虹伤害预览.gif)。

抽牌动画动态预览：[霓虹抽牌](docs/预览/抽牌动画/抽牌动画预览.gif)。五张错峰发牌约 0.60 秒完成，落稳后即可操作，余光继续淡出。

弃牌动画动态预览：[霓虹弃牌](docs/预览/弃牌动画/弃牌动画预览.gif)。单张弃牌飞行约 0.40 秒，非致命攻击仍在命中后解锁；致命攻击停留 0.52 秒后进入结算转场。

## 同步完成的清单内容

- 共用 HUD：左上显示 HP，非战斗页面正上显示七格日期条。新游戏 **100/100 HP、第 1 天**。
- 医院／地下诊所：每次恢复最大 HP 的 **30%**，封顶最大值。原型阶段免费、不耗时，未增加其他限制。
- F1 面板：测试信用点、HP 50／90／1／100 与日期 +1。
- 移动、对白、出牌、结束回合、治疗不会自行推进日期；第 7 天之后不进入未设计内容。
- 进出战斗使用同一套自下而上覆盖的彩色霓虹花屏；完全遮住画面后切场景，再消退开放输入。
- 战斗背景取当前事件地点；对白立绘与战斗立绘分别配置。
- 接入 `诺伦战斗立绘.png` 与 `机甲boss战斗立绘.png`，后者用于 E12／机甲演练的复仇机甲；可在敌人配置中替换。其他敌人战斗图保持空引用。
- 菜单、地图、对白、治疗与战斗按钮统一使用居中文字、略加粗的中文字体、霓虹角标、悬停亮边和按下反馈。
- 手牌悬停抬升、选中发光；出牌飞向目标并产生命中脉冲，抽牌采用错峰并行动画。
- 主菜单增加义体页，目录初始为空；独立局外 `meta_profile.json` 不随新冒险重置。

## 城市地图的素材边界

更新文档明确：**城市总览插画尚未提供**。因此不再把港口场景当作正式城市地图，也移除了旧点线连接。

`data/map.json` 使用独立 `cityMapAssetId`，当前 path 为空，画面明确显示“城市地图插画待补”。比例坐标热点、主线／可选数量标记、已完成／锁定状态、地区事件面板及治疗入口已可验证。正式总览图到位后，配置资源路径与精确地区边界即可接入；当前锚点仅为调试布局。整体画布缩放时热点随底图区域一起缩放。

## 存档兼容与恢复

冒险检查点为 `user://checkpoint.json`，备份为 `.bak`。macOS 默认目录：`~/Library/Application Support/MidnightCommissionDemo/`。

R1 使用 schemaVersion 2，自动读取并迁移初版存档：保留原剧情、目标、阵营、信用点及领取记录，补充 HP 100、最大 HP 100、第 1 天和空战斗字段。写入仍采用临时文件替换及备用检查点。

每次出牌与结束回合保存玩家 HP、敌人 HP、当前意图、回合数和三个牌堆；默认原型已验证中途保存与恢复。扩大敌人血量或改变牌组前，需检查[维护文档](docs/维护文档.md)中的首回合空手恢复边界，不能把原型测试直接当作扩展后也安全的保证。演练不写入上述文件。零 HP 进入战斗会进入失败流程，需要在开放的治疗地点恢复生命。

局外义体存档为同目录的 `meta_profile.json`，初始 `cyberwareState` 为空，当前不提供装备或属性效果。
