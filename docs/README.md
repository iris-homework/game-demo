  输出到 `artifacts/icon-previews/all-locations/`，可按图标说明重新生成。
  运行时内容以工程脚本、场景和 `data` 为依据。

## 文档如何随开发更新

修改功能时同步维护对应说明，记录日期、适用版本和实际检查范围。

| 发生的变化 | 需要同步的文档 |
| --- | --- |
| 玩法、卡牌效果、数值、治疗或日期规则变化 | 游戏规则；涉及技术边界时更新维护文档与接入说明 |
| 页面入口、事件条件、分支或胜败返回变化 | 游戏流程与路由；涉及数据接口时更新接入说明 |
| 美术方向确认、样板制作或资源接入 | 美术方向或对应样板文档，明确设计与接入状态 |
| 工具、agent 分工或 QA 入口变化 | 开发工具与工作流；涉及协作约定时更新 AGENTS |
| 任意交付变更 | 修改记录；必要时更新本索引和工程 README 的入口 |

规则和流程文档说明当前实现，不替代技术维护约定；修改记录说明历史，
不替代当前规则。阶段验收按本次实际结果记录，未运行的检查明确写未运行。
