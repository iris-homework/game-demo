这份清单用于收集当前游戏需要的音效。优先寻找对话短音、卡牌操作和正式敌人攻击声，
再补战斗效果、交易奖励与环境氛围。每项附有用途、优先级和搜索关键词。

核查日期：2026-10-24（Asia/Shanghai）。依据当前资源、脚本和配置静态核查，
未启动游戏、试听或进行实际听感验收。本次仅整理文档，未接入新声音。

## 可选氛围与已有声音升级

以下项目可以在操作反馈齐备后再收集。当前未发现背景音乐和环境循环声接入。
地点可按环境类型共用循环音，不必为17个地点分别制作一套。

- [ ] 菜单雨声与酒馆底噪：`rain window`, `bar ambience`。
- [ ] 城市远处车流与低频环境声：`distant traffic`, `city ambience`。
- [ ] 工业机械、电流与设备低鸣：`industrial ambience`, `electrical hum`。
- [ ] 港口水声与泵站流水：`harbor water`, `water pump ambience`。
- [ ] 室内设备、实验室仪器底噪：`laboratory ambience`, `machine room hum`。
- [ ] 替换简易命中声：可找肉体、金属、重击三组。
- [ ] 替换简易受击格挡声：更清晰的金属碰撞或护盾受击声。
- [ ] 分开斩击与突刺：当前两种动作共用一个采样，细分为后续增强。

背景音乐另行收集，可先分主菜单／酒馆、城市探索、战斗、胜败结算四种用途。
音乐与环境循环声不计入前面的短音效用途。

## 音效文件放置与命名

新收集的音效统一放进工程的 `assets/audio/incoming/`。这是本次新建的候选收集目录，
按用途分类；已有 `assets/audio/combat/` 保留现有引用。
候选目录中的 `.gdignore` 用于让Godot跳过该目录，收集文件不会自动接入或播放。
后续接入时，将选定素材复制到正式资源位置，再修改播放代码或动作帧绑定。

### 分类目录

你可以按下列目录直接放文件。一个声音用于多处时，只保存一份，在登记表注明复用编号。

```text
assets/audio/incoming/
├── .gdignore
├── source_info.txt          来源与用途登记
├── _originals/              下载原件、压缩包、原始许可，保留原文件名
├── dialogue/                对话逐字短音、推进声
├── ui/                      按钮、确认、取消、弹窗、错误提示
├── cards/                   悬停、选中、出牌、抽牌、弃牌、洗牌、消耗
├── combat/                  通用战斗、装填、格挡、弹反、状态、科技
├── enemies/                 敌人专属攻击／技能／死亡声，按敌人子目录存放
├── world/                   地点、转场、委托、交易、奖励、胜败、治疗
├── ambience/                雨声、城市、港口、机械等环境循环声
└── music/                   背景音乐候选
```

通用近战命中声放 `combat/`；鱼专属咬合声放 `enemies/fish/`。
卡牌悬停和点击选中放 `cards/`，普通菜单按钮点击放 `ui/`。
背景音乐单独放 `music/`，环境底噪放 `ambience/`。

### 文件命名

候选副本统一使用小写英文、数字与下划线，按“对象或用途＋动作＋两位序号”命名。
原始下载文件另存 `_originals/`，原文件名及许可文件保持原样。

```text
对象或用途_动作_01.wav
同用途的另一个候选：对象或用途_动作_02.wav
同一候选的加工版本：对象或用途_动作_01_v2.wav
循环素材：环境或场景_loop_01.ogg
```

序号 `_01`、`_02` 表示不同候选或声音变体；版本 `_v2`、`_v3` 表示同一候选的裁剪、
降噪或其他加工。保留原版本，避免覆盖后无法比较。
声音文件名使用下划线连接，不使用空格、中文括号、“最终版”或“新建文件”等含糊名称。
清单编号如 `CARD-02` 填在登记表中，不必写进文件名。

### 收集完成后交接

每批素材准备好后，记录用途与偏好即可交接，不需要手动修改Godot导入文件。

1. 将原件放入 `_originals/`，将候选副本放入对应分类目录。
2. 为同用途的多个候选编号，注明最喜欢的一份。
3. 在 `source_info.txt` 或登记表填写清单编号、候选路径、原始文件名、来源与备注。
4. 标明“待试听”或“试听认可”；接入与动作同步检查完成后再记录“运行接入”。
