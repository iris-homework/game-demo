## 构建

在 macOS 安装 Godot **4.7.2 标准版**及同版本官方导出模板。`tools/build_release.py` 使用 Python 3.9+ 和系统 `ditto`，不依赖第三方 Python 包。模板放在 `~/Library/Application Support/Godot/export_templates/4.7.2.stable/`，至少包含 `windows_release_x86_64.exe`、`macos.zip`、`version.txt`、`icudt_godot.dat`。官方模板下载入口：https://godotengine.org/download/archive/4.7.2-stable/ 。

从工程根目录执行：

```sh
python3 tools/build_release.py --output "$HOME/Desktop/game-demo发行版_新构建"
```

输出目录必须尚不存在，脚本不会覆盖既有交付。可用 `--godot` 指定引擎完整路径。脚本将当前磁盘上的运行时文件复制到系统临时目录，先导入再依次导出 Windows x86_64 与 macOS Universal 2；临时副本及日志位置记在 `构建记录/build.json`。不会运行正式工程、带入用户存档或自动提交／推送。

`export_presets.cfg` 定义发行配置。`project.godot` 开启 `textures/vram_compression/import_etc2_astc`，满足 Apple 芯片导出器检查，仍使用 Compatibility 渲染。保留当前游戏版本 `0.4.0-noren-cards`，没有更改玩法或存档结构。

## 交付内容

- `MidnightCommission-Windows.zip`：解压后双击 `MidnightCommission.exe`，同目录 `MidnightCommission.pck` 必须一起保留。
- `MidnightCommission-macOS.zip`：解压后双击 `MidnightCommission.app`，包含 Intel x86_64 与 Apple arm64；最低系统版本分别为 macOS 11 和 13。
- 两包均附 `开始游玩.txt` 和 `Licenses/`。无需额外安装引擎或联网。
- 输出根目录另存 SHA256、源文件哈希和构建日志；这些不需要发给玩家。

保留正式场景、脚本、shader、游戏数据、中文字体、正式素材及敌人管线 `runtime/`、`published/`。`assets/combat_test/` 和 `scripts/combat/test_stage.gd` 实际用于正式战斗，必须保留。动态读取的游戏 JSON、地图地点目录和管线目录显式纳入。

排除测试、开发工具、文档、美术制作记录、候选音效、制作台、源工程缓存、管线备份及用户存档。PCK 中由导出器生成的 `.godot/imported`、UID 与脚本映射属于运行数据，不能从发行包删除。

## 验证

先验证 ZIP 解压、文件哈希、Windows PE 架构、macOS 双架构与 `codesign --verify --deep --strict`。从解压后的 Mac 应用执行 headless 启动检查，日志写到临时目录。

`tools/release_smoke.gd` 可在 Godot 编辑器二进制中直接加载**导出的 PCK**，检查导出后的 JSON、图片、字体、脚本、场景与动态引用，打开菜单／牌库／新冒险，以及十个敌人和四个经典战斗入口，各执行一个敌方回合。必须设置绝对路径的 `MIDNIGHT_QA_OUTPUT` 并提前创建该目录。脚本关闭保存、将检查点与局外存档重定向至该目录，不发系统鼠标输入。

进程工作目录也必须使用不含`project.godot`的独立QA目录。仅指定`--main-pack`不能替代工作目录隔离；从源工程目录运行会被“不是源工程”断言拒绝。`--log-file`同样指向QA目录。

```sh
mkdir -p /tmp/midnight-package-qa
cd /tmp/midnight-package-qa
MIDNIGHT_QA_OUTPUT="/tmp/midnight-package-qa" \
  /Applications/Godot.app/Contents/MacOS/Godot --headless \
  --main-pack "/完整路径/MidnightCommission.pck" \
  --script "/完整工程路径/tools/release_smoke.gd" \
  --log-file "/tmp/midnight-package-qa/godot.log"
```

这验证的是导出资源和运行逻辑；Windows PCK 在 Mac 上通过不代表 Windows exe 已在 Windows 上运行，headless 不代表画面、实体输入、完整七天流程或 Intel 真机已验收。正式发行配置保持存档目录 `MidnightCommissionDemo`，与本机工程试玩共用进度；玩家包不附带存档。
