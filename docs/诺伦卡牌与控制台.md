# 诺伦卡牌与控制台

适用版本：0.4.0-noren-cards，2026-10-16。来源为工程同级的《卡牌和特殊效果设计/诺伦角色卡牌完整卡表.md》。40 种卡已接入可执行效果；数值仍是首轮试玩版本，未宣称完成实战平衡。

维护实现时先读[卡牌与效果实现维护指南](卡牌与效果实现维护指南.md)，其中包含逐卡配置、结算顺序、代码入口和改动后验证清单。本文保留玩家规则与控制台用法。

## 拥有牌与初始牌

新委托仅拥有 10 张：直击 ×4、护身 ×4、贴近 ×1、拉开距离 ×1。C、B、A、S 分别为灰、蓝、红、金色，种类分布为 4、22、10、4。牌库默认显示“已拥有”，可切换“全部卡牌”查看 40 种定义；未获得的卡不会自动加入牌组。同名卡显示拥有份数。

`startingDeck` 保存固定初始牌，`state.deck` 只保存额外获得的卡，允许重复。正式战斗与演练都复制当前拥有牌组；演练的生命、资源、消耗、结局不写回冒险。开始新委托清空额外获得的牌。

## F2 卡牌控制台

先开始或继续委托，在动作结束后按 **F2**（部分 Mac 键盘为 **fn+F2**），输入指令并回车。Esc 或 F2 关闭；↑／↓ 浏览本次指令历史。开发开关为 `data/config.json` 的 `developmentMode`。

```text
help
cards
cards 连射
owned
addcard 短点连射 2
addcard 36 2
addcard noren_36 2
```

- `cards [关键词]` 列出编号、中文牌名、品级和 ID；卡表 01—40 对应 `noren_01`—`noren_40`。
- `addcard <牌名/编号/ID> [数量]` 默认加 1 张，数量必须为 1～99 的整数。后三条示例是等价的三种写法，逐条输入会分别加牌。
- 指令加入当前冒险并保存，下一场战斗／演练生效，不往进行中的战斗插牌。在演练中不能永久加牌，请先退出演练。写盘失败时撤回本次加牌。
- 控制台打开时暂停底层页面处理并禁用其按钮，避免输字推进对白或点击穿透战斗。输入不作为任意代码执行。

## 战斗操作与规则

开场洗牌，初始近战、2 颗弹药，每回合 3 能量、抽 5 张；弹药上限 6。抽牌效果可以超过 5 张。回合结束弃置剩余手牌，抽牌堆空时回收弃牌堆并洗牌。玩家格挡在下一玩家回合开始清除。

非攻击牌选中后跟随鼠标并优先接管左键，自身／群体非攻击牌在整个游戏画面内点击或拖放即可使用；点击其他手牌或按钮不会触发其操作。首次原地选牌松手不出牌，不显示释放大框或提示文字。需要敌人的技能仍须点有效敌人，点其他位置保留选中；右键／Esc 取消后恢复正常按钮操作。攻击牌保持贴底居中置顶及原有目标要求。拆卸弹药会弹出攻击牌选择；过载射击与终结弹会弹出额外耗弹数量选择，可以选 0。取消选择不扣费、不弃牌。

| 机制 | 当前行为 |
| --- | --- |
| 近战 | 每张攻击获得 1 弹药，多段／群攻只计一次，卡面额外回弹另算 |
| 远程 | 每张攻击通常耗 1 弹药；无弹药不能攻击；本体伤害 ×1.5，逐段四舍五入 |
| 切换奖励 | 实际进入近战抽 1；实际进入远程的下张攻击费用 −1，不叠加且保留至使用 |
| 攻击后切换 | 切入斩、撤步反击先按用牌时的形态结算攻击和弹药，再切换 |
| 增伤 | 基础伤害先加增伤再乘倍率；标注“第一段”的增伤只加第一段；群攻的第一段作用于各目标 |
| 裂伤 | 远程每段先结算本体，再按当前裂伤结算额外伤害并减 1；不乘远程倍率。攻击牌的新裂伤在全部攻击后施加 |
| 裂伤施加 | 远程用牌施加量减半并四舍五入；弹反附带的 1 层不减半 |
| 弹反 | 一次敌方攻击结束后，每层反击一次；每次为该次受虚弱影响后、格挡前总伤害的 25%，四舍五入，并施加 1 裂伤。多段合并触发，最后只消耗 1 层 |
| 虚弱 | 每层降低敌人攻击伤害 10%，最多 5 层；逐段伤害四舍五入 |
| 持续 | 弹药、弹反、裂伤、虚弱跨回合保留；战斗结束重置；本回合增伤和本回合减费在回合结束清除 |
| 消耗、能力 | 进入独立消耗区，不再抽回；能力本场持续，同名再次使用仍扣费并离开循环，但不叠加效果 |

本轮对卡表未明确的格挡交互采用统一普通伤害口径：裂伤与反击也先扣格挡；只有明确写“无视格挡”的远程贯穿重弹本体绕过格挡。玩家若被攻击降至 0 HP，失败优先于同次弹反造成的击杀。

近战使用已有冲刺挥刃演出；远程使用已有持枪待机／射击图，距离过近时先后跳。卡牌使用数据排版的彩色卡面，没有新增独立卡图。

## 数据与存档接口

- `data/cards/cards.json`：40 种定义、完整 `description`、较紧凑的 `cardText`、`rarity`、费用、目标和效果。
- `data/combat/noren.json`：`ruleset: noren_v1` 及能量、弹药、开场洗牌等参数。`player_characters.json` 的 `combatRules` 指向此规则。
- `CombatModel`：所有扣费、伤害、抽牌、弃牌、状态、胜负；视图只消费一次提交的结果。
- 新快照包含 `norenState` 和 `openingDrawDone`。消耗区也参与实例唯一性校验；空手恢复不补发开场手牌。
- 冒险 schemaVersion 仍为 2。旧战斗保留自己的测试牌、旧规则和科技，不被中途重建。旧奖励和已拥有测试牌继续可加载；新战斗使用新初始牌加已有额外牌。
- 新战后奖励保留原 1000 CR／三选一流程，从 36 种非 C 牌中等概率抽三个不同定义；目前未设品级权重。旧待领奖励保持原候选。

## 验证与边界

专项入口：`tests/noren_cards_tests.tscn`（40 牌双形态、状态／资源边界、存档与控制台），`tests/noren_cards_visual.tscn`（卡面、拥有牌、选择窗口、动画和回合），`tests/noren_input_visual.tscn`（输入与近距离射击）。测试关闭保存或使用专用路径。

主菜单战斗演练、机甲演练及三人动作测试的每名对手均为 100 HP；正式剧情敌人仍沿用 3 HP／攻击 1 的测试数值。多段敌方攻击仅在 QA 夹具中构造，未据此宣称正式战斗难度已平衡。卡牌升级、移除牌组和商店构筑界面未加入。窗口中的合成输入检查不能代替真人鼠标／触控板完整游玩。
