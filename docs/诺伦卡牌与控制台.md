# 诺伦卡牌与控制台

适用版本：0.4.0-noren-cards，卡牌规则整理于2026-10-20。来源为工程同级的《卡牌和特殊效果设计/诺伦角色卡牌完整卡表.md》。40 种卡已接入可执行效果；数值仍是首轮试玩版本，未宣称完成实战平衡。

维护实现时先读[卡牌与效果实现维护指南](卡牌与效果实现维护指南.md)，其中包含逐卡配置、结算顺序、代码入口和改动后验证清单。本文保留玩家规则与控制台用法。

## 拥有牌与初始牌

新委托仅拥有 10 张：直击 ×4、护身 ×4、贴近 ×1、拉开距离 ×1。C、B、A、S 分别为灰、蓝、红、金色，种类分布为 4、23、9、4。牌库、当前卡组和控制台统一按C → B → A → S排列，同级按原编号升序；只改变展示副本，不改变实际抽取顺序。牌库默认显示“已拥有”，可切换“全部卡牌”查看 40 种定义；未获得的卡不会自动加入牌组。同名卡显示拥有份数。

游戏右上角 **牌库** 打开只读的“当前卡组”：同名卡合并并标数量。地图、对白等非战斗页面显示当前拥有牌；战斗和演练显示本场快照中的完整卡组，包含手牌、抽牌、弃牌和消耗区，控制台在战斗中添加的牌立即进入本场抽牌堆，并计入当前卡组。× 或 Esc 关闭并回到原页面，不退出战斗。主菜单牌库继续提供“已拥有／全部卡牌”切换。

2026-10-22新增分类筛选：主菜单牌库与当前卡组均可按**品级（C／B／A／S）、基础费用（0／1／2／3+）、类型（攻击／技能／能力）**组合查找，每组也可选“全部”；三组条件须同时满足。当前选项以持续底色和边框标识，顶部显示命中种数与拥有张数。切换“已拥有／全部卡牌”保留分类；“清除筛选”只清分类，重新打开页面恢复默认。费用按所显示卡牌的基础定义分类，战斗当前卡组使用本场冻结定义，不随临时减费变化。筛选不改变拥有牌、出牌顺序或存档。

`startingDeck` 保存固定初始牌，`state.deck` 只保存额外获得的卡，允许重复。正式战斗与演练都复制当前拥有牌组；演练的生命、资源、消耗、结局不写回冒险。开始新委托清空额外获得的牌。

## Ctrl+Shift+A 卡牌控制台

先开始或继续委托，在动作结束后按 **Ctrl+Shift+A**，打开即显示全部 40 种卡牌的名称、彩色稀有度与已有数量。点击任意卡牌加入 1 张，重复点击可继续添加，已有数量即时更新；下方显示操作结果。也可在底部输入指令并回车。Esc 或 Ctrl+Shift+A 关闭；输入框中 ↑／↓ 浏览本次指令历史。开发开关为 `data/config.json` 的 `developmentMode`。

```text
help
cards
cards 连射
owned
addcard 深度伤口 2
addcard 36 2
addcard noren_36 2
kill
```

- `cards [关键词]` 列出编号、中文牌名、品级和 ID；卡表 01—40 对应 `noren_01`—`noren_40`。
- `addcard <牌名/编号/ID> [数量]` 默认加 1 张，数量必须为 1～99 的整数。后三条示例是等价的三种写法，逐条输入会分别加牌。
- 点击和 `addcard` 均在战斗中直接把新实例放入抽牌堆顶，下一次抽牌优先抽到，不直接发入手牌。正式冒险同时保存拥有牌及开局记录，退出重开本场仍保留新增牌；写盘失败撤回整次加牌。非战斗页面加牌用于之后的战斗。
- 演练中允许临时加牌，仅加入本场抽牌堆，不增加永久拥有数量；结束或退出演练恢复原冒险。
- `kill` 无参数，使当前全部存活敌人生命归零，无视格挡，沿用死亡效果、胜利及奖励流程；成功后自动关闭控制台。双人舞者一阶段会正常进入二阶段，二阶段再输入 `kill` 才会胜利。仅开发模式、战斗空闲且未结束时可用，保存失败撤回本次操作。
- 控制台打开时暂停底层页面处理并禁用其按钮，避免输字推进对白或点击穿透战斗。输入不作为任意代码执行。

## 战斗操作与规则

开场洗牌，初始近战、2 颗弹药，每回合 3 能量、抽 5 张；弹药上限 10。抽牌效果可以超过 5 张。回合结束弃置剩余手牌，抽牌堆空时回收弃牌堆并洗牌。玩家格挡在下一玩家回合开始清除。

攻击牌与需要指定敌人的技能牌采用相同居中瞄准操作：按住拖到有效敌人后松开，或先选牌再点敌人；空地松手保留选择，可点同牌取消、切换手牌、右键／Esc取消。自身／群体非攻击牌选中后跟随鼠标并优先接管左键，在整个游戏画面内点击或拖放即可使用；点击其他手牌或按钮不会触发其操作。首次原地选牌松手不出牌，不显示释放大框或提示文字。“加深伤口”“引伤标记”“血迹追踪”及远程“稳住阵脚”采用指定敌人的操作，近战“稳住阵脚”仍对自身使用。拆卸弹药会弹出另一张任意类型手牌的消耗选择；所选牌进入消耗区，本牌进入弃牌堆，取消时不扣费、不补弹、不移动牌。火力倾泻自动消耗全部弹药，终结弹只消耗通常的1颗弹药，均不弹出额外耗弹选择。打出前用右键／Esc取消选牌不会扣费。

| 机制 | 当前行为 |
| --- | --- |
| 近战 | 每实际打出一段攻击获得1颗弹药；多段逐段回弹，群攻同一段只计一次。完全格挡也计段，击杀后未打出的段数不计；卡面额外回弹另算 |
| 远程 | 每张攻击通常耗 1 弹药；无弹药不能攻击；本体伤害通常×1.5，弱点瞄准生效后×2，逐段四舍五入。火力倾泻耗尽全部弹药，总段数为1+打出前弹药数 |
| 贴近 | 1费技能；获得1层弹反，进入近战形态；弹反上限3层，已在近战时仍获得弹反，但不触发切换抽牌 |
| 切换奖励 | 实际进入近战抽 2；实际进入远程的下张攻击费用 −1，不叠加且保留至使用 |
| 攻击后切换 | 切入斩先按用牌时的形态结算两段攻击和弹药，再进近战。快速装填是技能，先获得2弹再进入远程 |
| 增伤 | 基础伤害先加增伤再乘倍率；标注“第一段”的增伤只加第一段；弱点锁定改为下一张攻击每段基础伤害+6，两类可叠加；群攻对各目标适用 |
| 裂伤 | 远程每段先结算本体，再按当前裂伤结算额外伤害并减1；不乘任何远程倍率。伤口追猎近战与远程均合计触发2次；深度伤口生效后不再减层。攻击牌的新裂伤在全部攻击后施加 |
| 裂伤施加 | 远程用牌施加量减半并四舍五入 |
| 弹反 | 最多3层，层数只决定可触发次数；一次敌方攻击结束后只反击一次，造成该次格挡前总伤害的50%（四舍五入），获得1颗弹药并消耗1层。多段攻击合并触发 |
| 虚弱 | 有层数时固定降低敌人攻击伤害 25%，与层数无关；逐段四舍五入。该敌人回合结束减 1 层，0 层失效，最多 999 层 |
| 持续 | 弹药、弹反、裂伤跨回合保留；虚弱每次该敌人回合结束减 1 层；战斗结束重置；本回合增伤和本回合减费在回合结束清除 |
| 消耗、能力 | 进入独立消耗区，不再抽回；能力本场持续，同名再次使用仍扣费并离开循环，但不叠加效果 |

本轮对卡表未明确的格挡交互采用统一普通伤害口径：裂伤与反击也先扣格挡；当前新卡均不无视格挡；旧战斗快照中的贯穿重弹仍按其旧定义让远程本体绕过格挡。玩家若被攻击降至 0 HP，失败优先于同次弹反造成的击杀。

近战使用已有冲刺挥刃演出；远程使用已有持枪待机／射击图，距离过近时先后跳。卡牌使用数据排版的彩色卡面，没有新增独立卡图。

## 数据与存档接口

- `data/cards/cards.json`：40 种定义、完整 `description`、较紧凑的 `cardText`、`rarity`、费用、目标和效果。
- `data/combat/noren.json`：`ruleset: noren_v1` 及能量、弹药、开场洗牌等参数。`player_characters.json` 的 `combatRules` 指向此规则。
- `CombatModel`：所有扣费、伤害、抽牌、弃牌、状态、胜负；视图只消费一次提交的结果。
- 新快照包含 `norenState` 和 `openingDrawDone`。消耗区也参与实例唯一性校验；单个快照的空手恢复不补发开场手牌。2026-10-22 起，新正式战斗退出后改从独立 `battleStart` 恢复，再按固定牌序执行一次首抽；没有开局记录的旧战斗仍按原快照继续。
- 冒险 schemaVersion 仍为 2。旧战斗保留自己的测试牌、旧规则和科技，不被中途重建。旧奖励和已拥有测试牌继续可加载；新战斗使用新初始牌加已有额外牌。
- 战后奖励保留 1000 CR／三选一流程。每个候选先抽品级，再在该级剩余卡中等概率选卡；普通 B／A／S 为60%／37%／3%，精英为50%／40%／10%，Boss为0%／0%／100%。C 不参与，三张 ID 不重复，无隐藏保底；现有八场仍全为普通。已生成的待领奖励保持原候选，未生成的使用新规则；完整边界见[奖励领取](游戏规则.md#奖励领取)。
