# 主菜单重构规划与任务清单

本文把主菜单讨论整理为可执行方案，当前基线为 **0.2.6-r1**，记录日期为
**2026-10-07（Asia/Shanghai）**。P0 已按本方案以 0.2.5-r1 接入，0.2.6-r1 起
背景改用用户审核的逐帧动画；本文保留原有规划设计历史，最终验收细节见
[主菜单验收记录](主菜单验收记录.md)。

规划按讨论中推荐的“酒馆窗边＋委托终端”展开，作为首版制作方向；0.2.5-r1
首版使用用户 `asset/source` 原始资源的工程副本，0.2.6-r1 换成用户审核的
`noren-bar-idle-motion-v2-neon.gif` 逐帧动画，构图与姿态以接入代码为准，
不把规划草图写成已定稿美术。

## 目标与现状

让玩家打开游戏时先感受到“雨夜都市里，一份委托正在等待诺伦”，并能快速
找到继续和新游戏。静态构图先成立，再通过局部环境运动增加气氛。

接入前曾静态核对 [menu.gd](../scripts/menu.gd)、[menu.tscn](../scenes/menu.tscn)、
[Game](../scripts/game.gd) 与 [DemoUI](../scripts/ui.gd)。重构后的 `menu.gd`
在 0.2.5-r1 使用左侧 500px 栏，0.2.6-r1 改为右侧 350px 栏；背景与角色由
[menu_environment.gd](../scripts/menu/menu_environment.gd) 提供，并已有逐帧动画、
静态模式与 UI 淡入。0.2.5-r1 的雨、霓虹、终端状态灯属 P0 历史。历史截图可用
于接入前构图对照，不代表本轮重新运行。

下表是接入前的问题与首版目标，保留为设计历史。

| 接入前问题 | 首版目标 |
| --- | --- |
| 大面板遮住大半背景，场景存在感弱 | 用左侧局部渐暗保障文字可读，保留完整场景 |
| 文案和辅助按钮密集，演练入口抢眼 | 继续／新委托为主要操作，演练与档案降低视觉权重 |
| 主菜单继续使用城市总览视角 | 增加人物与近景道具，形成有故事感的入口 |
| 动画制作范围尚不明确 | 首版只做雨、局部灯光和终端提示灯三项环境效果 |

## 首版画面方案

以下为 0.2.5-r1 P0 的静态构图方案，属设计历史。0.2.6-r1 背景改为用户审核的
逐帧动画：诺伦坐在左吧台，菜单列移到右侧 350px，画面由
`noren-bar-idle-motion-v2-neon.gif` 逐帧重建。

画面为酒馆内向窗外看：诺伦位于右侧，首版使用用户原始立绘的静止站姿，
不再新画侧影、背影或坐姿；桌面上放置程序绘制的委托终端；窗外城市的青色与
洋红霓虹映入室内。角色首版保持静止。

- 左侧约 35% 留给标题、一句文案和主菜单，避免高亮招牌、人物或杂物穿过文字。
- 右侧约 65% 形成视觉中心：人物、窗框、桌面终端与城市灯光有前后层次。
- 标题采用现有中文字体进行界面排版，英文副标题降低权重；不将中文菜单
  或动态信息画死在背景图里。
- 菜单使用克制的深色底与清楚的浅色文字，主操作用项目既有强调色；人物
  与环境可以偏暗，按钮、标题和焦点必须清楚。
- 继续使用 1440×900 逻辑画布。背景建议按 16:10 制作，并预留边缘裁切余量；
  16:9 窗口先遵循现有等比缩放与留边策略，不为本轮菜单改整个工程的缩放规则。

示意布局如下，位置在静态样板阶段校准：

```text

│ 午夜委托                 窗框／雨夜城市／局部霓虹        │
│ MIDNIGHT COMMISSION                                      │
│ 一句短文案                         诺伦（原静止立绘）    │
│                                                         │
│ 继续委托                                                │
│ 地点 · 阵营（有有效进度时）         桌面／委托终端        │
│ 新的委托                                                │
│                                                         │
│ 义体档案    演练                    动态效果开关 · 版本  │
└─────────────────────────────────────────────────────────┘
```

## 菜单入口与状态规则

沿用既有流程接口，菜单重构只改变展示和入口组织。没有实际功能的入口不作为
装饰性按钮上线。

| 入口／状态 | 首版行为与实现边界 |
| --- | --- |
| 继续委托 | 沿用 `Game.resume()`；无内存进度且无存档时禁用，有进度时突出 |
| 新的委托 | 沿用 `request_new()` 与 `Game.new_game()`；有进度时保留覆盖确认及取消 |
| 义体档案 | 保留 `Game.open_cyberware()`，不因新菜单添加装备或属性功能 |
| 演练 | 收入一组次级入口，仍可分别进入 B04 战斗演练与 B12 机甲演练 |
| 进度摘要 | 只读真实的当前地点与阵营；尚未选择阵营时显示现有对应名称 |
| 仅磁盘存档 | `has_save()` 只代表文件存在；摘要须经验证后读取，不能为展示摘要触发恢复、推进或保存。首版可只显示“已有检查点” |
| 损坏或不兼容存档 | 沿用读取失败反馈，不虚构进度，不自动开始新游戏或覆盖原文件 |
| 动态效果开关 | 首版提供当前会话的静态模式；不写入冒险存档。跨启动记忆作为后续独立界面偏好 |
| 设置、退出 | 完整设置页和新增退出入口列为后续范围，不在首版放无效按钮 |

移入按钮只改变焦点和反馈，不启动任务或演练。键盘焦点清楚可见，Tab 切换
及 Enter／Space 激活按钮；弹窗打开后焦点留在弹窗。P0 实际接入时，新委托
确认默认焦点在“返回”，Tab 只在两个弹层按钮间循环；Esc 先关闭确认，再折叠
演练分组，最后交回主流程的既有恢复行为。

## 动态效果分级

首版只实施 P0；0.2.6-r1 起这类程序化环境效果由逐帧动画背景取代，下表属
0.2.5-r1 设计与调试历史。实际接入值以代码为准（P0 霓虹 6 秒、终端状态灯
3 秒、UI 淡入约 0.4 秒），性能结论仍以 `performance` 实际输出为准。

| 优先级 | 效果 | 实施方式与限制 |
| --- | --- | --- |
| P0 | 窗外细雨 | 用粒子或轻量着色器实现，限定在窗口区域；不落到标题、人物或按钮前面 |
| P0 | 局部霓虹变化 | 独立灯光遮罩，亮度缓慢变化，建议周期 4–8 秒；不用全屏明暗闪烁 |
| P0 | 终端提示灯 | 小区域轻微呼吸，建议周期 2–4 秒；不显示虚构的新任务通知 |
| P0 | 界面进入与按钮反馈 | 淡入约 0.3–0.6 秒，悬停反馈约 0.1–0.2 秒；按钮和文字位置稳定 |
| P0 | 静态模式与生命周期 | 关闭环境运动后保留清楚的静态画面；离开菜单释放动画、粒子和计时器，失去窗口焦点时暂停环境动画 |
| P1 | 前后景轻微视差 | 需要可拆分且补全遮挡区的素材；建议总位移控制在 4–8 逻辑像素，文字和按钮不跟随 |
| P1 | 杯口蒸汽、环境声 | 美术和音频到位后再加；音频须核对来源，设置可控制音量 |
| P2 | 人物呼吸、头发、衣物运动 | 需要拆层、补画或骨骼；不纳入首版验收 |
| P2 | 长视频、3D 场景、镜头漫游 | 暂缓，避免素材与运行成本扩大 |

难度主要集中在背景构图、光效遮罩和分层素材的质量；首版无需人物骨骼或
完整动画短片。若雨或灯光影响文字辨识，先降低效果强度再考虑增加装饰。

## 素材清单与工程组织

0.2.5-r1 首版使用用户原始资源限定：`assets/backgrounds/bar.png` 与用户
`D:/Major Project/GodotGameDemo/asset/source/场景/地下酒馆.png` 完全 SHA256 一致，
`assets/characters/noren.png` 与用户 `角色/诺伦.png` 一致，记录在
[assets/menu/source-manifest.json](../assets/menu/source-manifest.json)。该版使用
完整原酒馆与诺伦原静止站姿，雨、局部霓虹和终端状态灯在运行时生成。0.2.6-r1
起改用用户审核的逐帧动画 `assets/menu/noren-bar-idle-motion-v2-neon.gif`，逐帧
无损解码为 `assets/menu/noren_idle_frames` 下的 60 张 PNG；上述静止资源仅作
来源历史保留。早期“专用插画需要另行制作”属于接入前的规划判断，已由用户原
资源与后续审核动画取代。

| 素材 | 首版实际来源与要求 |
| --- | --- |
| 酒馆背景 | 用户 `场景/地下酒馆.png` 的工程副本 `assets/backgrounds/bar.png`；完整原图，保留左侧文字空间 |
| 诺伦立绘 | 用户 `角色/诺伦.png` 的工程副本 `assets/characters/noren.png`；原静止站姿，不新画坐姿或背影 |
| 窗口雨区域 | 运行时着色器只覆盖原图百叶窗玻璃区域，不越出窗框和人物 |
| 局部霓虹 | 瓶形招牌局部多边形遮罩，只影响已有招牌区域，不让建筑整体变形 |
| 终端状态灯 | 程序绘制的小型桌面道具与状态灯，不把可变文字或按钮画入背景 |
| 资源记录 | `assets/menu/source-manifest.json` 记录来源与 SHA256；未使用生成图片 |
| P1／P2 分层素材 | 视差、人物呼吸等仍需要拆层、补画或骨骼，不属于首版 P0 |

以下路径已创建并接入：素材记录 `assets/menu/`、逐帧素材
`assets/menu/noren_idle_frames/`、环境组件 `scripts/menu/`、P0 验证证据
`artifacts/qa/menu-redesign-2026-10-07/` 与 0.2.6-r1 逐帧背景证据
`artifacts/qa/menu-gif-2026-10-07/`。
继续以 [menu.tscn](../scenes/menu.tscn) 和 [menu.gd](../scripts/menu.gd) 为主入口，
背景效果位于 [menu_environment.gd](../scripts/menu/menu_environment.gd)；菜单按钮仍通过
`Game` 调用既有流程。动画不得写入剧情状态，装饰节点不得拦截鼠标。
