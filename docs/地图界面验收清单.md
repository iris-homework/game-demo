## 实施状态

地图使用 `assets/map/map.jpg` 和十七份素材中的十六个游戏地点符号。
教会仍为插画地标；革命军营地名称和全部地点 ID、条件、任务配置保持原有值。

| 元素 | 已实现行为 |
| --- | --- |
| 当前位置 | 青色图钉与诺伦圆头像，读取 `currentPlaceId` |
| 主线目标 | 所有符合事件条件和地点开放条件的未完成主线标金色，不任意指定唯一候选 |
| 任务与状态 | 主线 `!`、可选 `?`，多事件数量，锁定锁形和完成勾 |
| 同点与选择 | 当前与目标重合时金色图钉加青色头像；浅色选中外圈独立叠加 |
| 悬停 | 持续约 0.2 秒出现只读简介与任务信息，移开关闭；不叠系统 tooltip |
| 固定详情 | 点击固定一张卡；固定 A 时悬停 B 只高亮，点击 B 才换卡 |
| 关闭 | 空白或 Esc 关闭卡片；周次弹窗和开发面板先处理 |
| 操作 | 明确进入、任务、治疗按钮才提交；长文和多事件滚动，操作区保留在底部 |
| 刷新 | 治疗不移动当前位置，重建后恢复医院／诊所选择；离开再返回默认关闭详情 |

目标共用 `Game.map_target_events()` 与 `map_place_state()`。委托对象
`targetId` 和可能残留的 `activeEventId` 不当作地图目的地。无正式奖励、难度、
旅行耗时或费用字段时，地图不仿造这些内容；日期和存档 schemaVersion 2 未变。
