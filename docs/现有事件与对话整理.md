# 午夜委托：现有事件与对话整理

> 整理日期：2026-10-23（Asia/Shanghai）。以本制作工作区的 MidnightDemo 当前配置与脚本为准；含完整剧情剧透。对白原文按当前配置静态核对；刷新／日期规则及本轮验证见[修改记录](修改记录.md)。

## 1. 内容范围与阅读说明

- 当前接入第一周 **9个事件**：不分主线／支线，刷新时间均为随时；两条港口事件按委托目标互斥，单次正常冒险最多完成8个事件。
- 共 **93个节点**：69个普通对白／选择／结果文本节点、7个场景旁白节点、8个战斗节点、9个结束节点。含文本节点76个，其中8个仅为旧存档保留的投降文本。
- 共20个选项条目：委托选择2个、付款选择2个、战败返回8个、旧投降返回8个。实质剧情选择点只有 E01 的委托选择和 E03 的付款选择。
- 工作区的[地点事件与对话初稿](../../地点事件与对话初稿.md)包含六个未接入事件，本文仅整理当前游戏已接入的内容。
- 第二周、第三周的 `eventIds` 均为空，状态为 `pending`，当前没有后续周事件或对白。
- 下文保留当前全部对白、旁白、选择提示与选项原文，不润色或补写。相同的战败／旧投降文本集中放在第5节，每个相关事件均注明返回路径。
- `stage` 是场景叙述，也在对白页显示，需要继续推进；不是独立动画指令。说话者为空时界面显示“场景”，下文将叙述性文本标为“场景旁白”，选择提示标为“场景／选择提示”。
- 节点ID用于定位源配置；表中“下一步”是跳转信息，不属于对白。战斗与 `finish` 没有文本，另列战斗返回与结算效果。

## 3. 事件前置与刷新走向

```text
E01 午夜酒馆：选择理查德／卢米娜
  ├─ E02 骚动的垃圾场【可先获取信用点】
  └─ E03 蜂巢城寨的艾克：付费／战斗取得后巷线索
       → E04 后巷深处：战斗取得港口线索
       → E05A 理查德 或 E05B 卢米娜【按E01目标互斥】
            ├─ E08 赛博精神病
            ├─ E11 变异的鱼
            └─ E12 机甲复仇【完成第一周】
```

17个地点目前都可进入；事件仍需满足前置和刷新时间，全地图最多同时刷新3个，保留仍合格的已有项并随机补位。当前9个事件均为随时，但合格候选不保证立刻全部出现；地图和地点共用同一池，查看不会重抽。E02不是线索链必经点，E08、E11也不要求先于E12完成。

初始信用点为100，直接进入E03时“支付300信用点”不可选。可以先正常完成E02，获得1000信用点战斗奖励，再回蜂巢城寨付费；不必使用开发面板。

## 6. 结算与当前剧情边界

- **事件完成时机**：到达 `finish` 才首次追加事件完成记录并推进1天（第7天封顶）；重复完成不再耗时。打赢之后还需推进战后对白。E01与E03付费路线同样耗时；战败、移动、治疗、奖励选择与演练不耗时。日期最多第7天，不自动切周；旧档不按历史完成记录补算日期。
- **通用战斗奖励**：正式战斗胜利并完成战后对白后，一次到账1000信用点，并提供三张不同的非初始牌供选一张；可放弃选卡。E01与E03付费路线没有战斗胜利奖励。全部事件的 `rewardIds` 当前均为空，这不表示没有通用战斗奖励。
- **战斗分类**：8场均为普通战斗；E12虽是第一周终场、敌人ID含 `boss`，其配置仍为普通，不按名称推断类型。
- **主角身份**：两条港口路线都只是完成委托并交接，保持自由佣兵身份，没有现存阵营加入选择。
- **第一周落幕**：E12首次完成推进1天（第7天封顶）并写入完成旗标；第二、三周没有已接入事件，仍可探索剩余事件，地图继续显示其刷新标记。
- **尚未补完**：八个旧战败节点保留“后续剧情待补”原文，当前已由独立战败页替代；投降文本只作旧档兼容。E08的克拉拉没有后续对白；E11没有鱼的台词。本文不补写这些内容。
- **原文待审阅处**：E04的“港口！我听说他就在港口……”在两条目标路线共用；选择卢米娜时仍为“他”。本文保留源文，不自行改动游戏文案。
- **没有剧情事件的地点**：归零运动营地、沃斯大楼、发电厂、白昼庭院、末班车旅馆、科技教会、沃斯商场、黑市、医院、地下诊所。地点简介与治疗服务不算独立对白事件。
