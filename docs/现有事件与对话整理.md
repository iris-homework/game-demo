# 午夜委托：现有事件与对话整理

2026-10-23 更新。本文按本PR的事件配置整理当前内容，含完整剧透。

## 1. 当前事件与规则

- 当前有5个事件：E01、E02、E03、E04、E11；4场战斗：B02、B03、B04、B11。
- 五个事件的前置条件全部为无，刷新时间区间均为“随时”；不再区分主线／支线。
- 地图同时最多刷新3个事件，保留仍有效的已有项，空位从未完成候选中随机补齐；“无前置”不保证所有事件立即同时显示。地图和地点页共用刷新池，读档保留已刷新项。
- 每个事件首次完成推进1天，最多第7天，七格进度条到顶后保持7；战败、治疗、移动和奖励选择不额外计时。
- 新委托仍先进入E01开场；其他事件不再以完成E01、线索或委托目标为解锁条件。
- 支付选项自身的信用点要求保留。E03付费需要300信用点，初始100；可先完成一个战斗事件取得1000信用点奖励。
- 移除的两个港口追击事件、赛博精神病和机甲复仇不再刷新；当前没有配置第一周终局事件，也不会自动进入第二、三周。

### 动态文本

`@player` 表示当前主角，默认诺伦；`{主角姓名}`替换为主角姓名。E01仍可选择理查德或卢米娜作为对白中的委托目标，但不再解锁港口事件。未选择目标时，`{目标姓名}`显示为“委托目标”；未知的非空目标仍视为配置错误。空说话者在游戏中显示“场景”。

## 5. 奖励、存档与内容边界

- 正式战斗胜利并完成战后对白后，一次到账1000信用点并提供三张不同的非初始牌供选一张；可放弃选卡。4场战斗当前均为普通。
- 旧存档停在已移除事件的对白、战斗或结算时，非失败进度转回地图并使用保留事件的安全锚点；已失败的旅程保持战败终局。
- 已有信用点、卡牌、日期、生命和历史对白保留；退役事件的完成标记、刷新池引用和选择记录清理，未选的退役奖励关闭，不追发奖励或追算日期。保留战斗的开局快照与规则不重建。
- 旧的第一周完成旗标不再作为当前终局；当前没有新的完成整周条件。
- E04原文仍提及港口，作为现存对白保留，不代表港口事件仍可玩。
- 52个节点中有43个文本节点，含5个场景旁白；12个选项条目（4个剧情选项、8个旧结果返回选项）。
- 其余地点保留地点介绍和已接入服务，不因没有任务前置而新增事件。
