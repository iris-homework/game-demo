# 音效与正式场景模拟测试台

这个测试台保留正式场景模拟、候选试听和绑定，用于继续比较声音。2026-10-25 的
用户授权方案已经接入正式游戏：正式播放器只预载 `assets/audio/game` 中 18 个去重
文件，覆盖 27 个 cue 中的 21 个非空项；`reward`、`transition`、`turn_start`、
`victory`、`defeat`、`energy` 保持静音，正式战斗和测试台的归位
`snap` 已恢复播放，沿用原音源、−10 dB及归位触发时机。正式游戏不扫描 `incoming`，也不读取测试台保存的方案 JSON。

测试台仍保留 `incoming/` 的 96 个分类候选：75 个 Balatro OGG、1 个旧对话 MP3、
7 个对话候选，以及此前复制的 13 个参考候选。当前 21 个非空正式 cue 与测试台默认
共用同一组逻辑绑定；Cozy 柔和文字短音已进入正式目录，另外 78 个候选没有被复制到
正式运行资源，仍可在这里手动试听和绑定。每个动作的 incoming 路径、正式路径、
触发位置和替换方法见
[音效用途与替换表](测试台音效用途与替换表.md)。原名备份目录 `_originals/`
不重复列入候选。

正式与测试台共用播放边界。回合数字增加时，共享观察器跳过同一次快照中的能量、
弹药、格挡、弹反、形态和科技冷却反馈；战斗 **结束回合** 按钮不触发普通按钮声，
弃牌、抽牌和真正的攻击声仍保留。`energy` 的空绑定还会关闭卡牌或科技主动回能声。
对话继续使用同一个 `dialogue_blip` 文件，诺伦使用 `0.88`，NPC 与场景／旁白都使用
`1.0`。96 个测试候选和六个默认静音项保留；归位 `snap` 已恢复。

## 打开与操作

测试台沃斯商场的 **迅捷芯片** 售价设为 **9999 信用点**，初始余额仍为 2000，
因此该商品会显示余额不足、购买按钮不可用。这个价格和测试状态只存在于
`audio_preview_session` 模拟会话；正式售价仍为 150 信用点，正式游戏没有接入该价格、
测试状态或商店覆盖。退出测试台恢复进入前配置。

入口沿用现有敌人制作台。你可以继续调战斗，也可以打开新的场景模拟面板。

1. 在Godot打开[workbench.tscn](../enemy_asset_pipeline/workbench.tscn)，按 **F6**。
2. 点击上方 **音效与场景模拟**。
3. 在顶部选择 **对话、剧情选项、战斗交互、沃斯商场、黑市、奖励选卡、地图**。
4. 操作左侧正式页面，在右侧比较音效；点击 **返回战斗制作台** 恢复进入前的战斗。

独立入口为[audio_scene_simulator.tscn](../enemy_asset_pipeline/audio_scene_simulator.tscn)，
同样可按F6运行。独立运行结束后返回空场景；从工作台进入则返回原战斗。

## 试听与动作绑定

右侧提供候选搜索、分类筛选、试听、动作绑定和总音量。较长的环境声也可以直接试听，
默认方案只选取适合短反馈的候选。

| 操作 | 用途 |
| --- | --- |
| 搜索文件名／用途 | 按文件名筛选；英文动作名如 `select`、`hover`、`coin` 可检索 |
| 分类选择 | 查看各类候选；新分类在重开面板后出现 |
| 双击文件／试听所选 | 直接播放一个候选；再次试听前停止已有候选尾音 |
| 动作下拉框＋绑定所选 | 将文件用于按钮点击、对话、选牌、抽牌、交易等动作 |
| 此动作静音／试听动作 | 关闭选定动作的声音，或按当前绑定试听 |
| 停止全部 | 停止共享 cue 播放器；战斗刀声、枪声与已恢复的归位响指均沿用原设置 |
| 启用场景音效 | 控制页面观察器的自动反馈；转场、胜败及错误提示由模拟器直接播放，目前不受此开关控制；转场和胜败默认静音，错误提示仍可播放；手动试听仍可用 |
| 候选总音量 | 调节所有候选的播放音量，范围−40至0 dB |
| 重新扫描 | 读取新放入候选目录的OGG、WAV、MP3；保留有效的既有绑定和空字符串静音项 |
| 保存音效方案 | 保存本测试台的绑定与音量；后续打开测试台时读取，不修改正式游戏 |

测试台方案只用于预览：普通制作台保存到
`enemy_asset_pipeline/audio_preview_bindings.json`，测试版制作台保存到
`enemy_asset_pipeline/test/session/audio_preview_bindings.json`。只有明确点击保存才写
方案文件；正式 `game_audio.gd` 不读取这些 JSON。测试台重新扫描时，六个空字符串绑定
仍作为静音项保留。保存测试方案时把 `reward`、`transition`、`turn_start`、`victory`、
`defeat`、`energy` 写为空字符串，其他 21 个 cue 的测试绑定保持原样。

对话默认使用 `dialogue/dialogue_blip_cozy_soft_01.wav`（80 毫秒逐字节流），测试台可
换成其他候选；正式游戏使用 `assets/audio/game/dialogue/` 中的同一原字节文件。
自动逐字按当前对白节点的 `speakerId` 选择音高：`noren`，以及经
`Game.resolve_character_id` 解析为 `noren` 的 `@player`，使用诺伦的 `0.88`；其他非空
`speakerId` 使用 NPC 的 `1.0`；空 `speakerId` 使用旁白的 `1.0`。两档共用同一个
`dialogue_blip` 绑定文件，不新增 cue 或音频文件。`play_dialogue(role)` 只为当前自动
播放设置音高；普通音效和手动试听每次重置为 `1.0`，避免复用声道时串音。
要改两档音高，改共享核心 [sfx_player.gd](../scripts/audio/sfx_player.gd) 的
`DIALOGUE_PITCHES` 中 `noren`、`npc`、`narrator` 的数值。`audio_preview_bank.gd` 只是
继承共享核心的测试适配器，不应在这里另设角色音高；方案 JSON 保存的是共享绑定文件，
不保存角色音高。

新增备选包括 Cozy 低音／高音／木质音、Omori 文字音、逆转裁判男女短音，共 7 个文件，
都在 `incoming/dialogue/`；参考目录原文件保持原样。只有 Cozy 柔和文字短音已复制为
正式文件，其余 6 个仍只在测试台候选库。已保存的测试方案优先于测试台默认值；它不会
覆盖正式默认，也不会让正式游戏读取候选文件。
已有 `text-blip-14855.mp3` 长8.832秒，仍可完整试听或绑定。
**对话逐字** 最多播放100毫秒片段，并在末尾15毫秒淡出；原文件保持原样，
手动试听仍播放完整文件，并且固定为 `1.0` 原调。对话短音和卡牌悬停分别有
80／70毫秒节流，最多同时播放8声。两档角色音高只能在 **对话** 场景逐字显示时比较，
不能用候选试听或 **试听动作** 代替。

## 与正式游戏的边界

当前 27 项方案已经进入正式游戏，测试台继续作为开发比较工具。两边共享 cue 契约、
角色音高、八声播放器和观察器；正式与预览的资源根目录以及配置来源不同。

- 正式 [main.gd](../scripts/main.gd) 创建 `game_audio` 与共享 `sfx_hooks`，路由切页时
  attach／detach，并观察根级弹层按钮和错误提示。正式播放器只注册
  `assets/audio/game` 下的 18 个文件，不扫描 `incoming`，不读取方案 JSON。
- 测试台 [audio_preview_bank.gd](../enemy_asset_pipeline/runtime/audio_preview_bank.gd)
  仍扫描 `incoming`，`audio_scene_hooks.gd` 只是共享观察器的薄适配器。候选目录保留
  `.gdignore`，测试台保存的 JSON 只改变预览。
- 模拟进入时禁用冒险保存，改用专用且不会写入的检查点／元数据路径。对话、商店等
  页面执行真实规则，所有数据来自测试状态；返回时恢复原状态、版本号、训练标志、保存
  设置、元数据及事件／黑市独立随机状态。原战斗模型与手牌保持原样。
- 测试台迅捷芯片的 9999 信用点只用于模拟余额不足状态；正式售价为 150，正式游戏没有
  接入测试价格、测试状态或商店覆盖。
- 正式战斗和测试台的共享 `sfx_hooks.gd` 不再修改 `combat_audio.muted_cues`。
  `snap` 归位响指恢复播放，`combat_audio.LEVELS.snap` 沿用原音量 −10 dB。**结束回合** 按钮不触发普通
  `ui_click`；回合数字增加的那一次快照跳过 `energy`、`ammo`、`block`、`parry`、
  `stance`、`technology` 六项资源反馈。进入新回合后的弃牌、抽牌和真正的刀枪攻击仍
  播放。
- 更新正式声音时，先在 [sfx_player.gd](../scripts/audio/sfx_player.gd) 的
  `DEFAULT_BINDINGS` 确定相对路径，再按同一相对路径把原字节文件复制到
  `assets/audio/game`。若文件名或路径变化，同步修改 [game_audio.gd](../scripts/audio/game_audio.gd)
  的 `CLIPS` 与显式 `preload`，确保导出包携带原生导入后的资源。最后更新
  [sources.json](../assets/audio/game/sources.json) 的来源、SHA256 和许可状态。
- 正式制作包不发布全部 96 个候选、`incoming`、`_originals` 或 `reference` 目录，只
  发布当前 18 个正式文件及其许可登记。`sources.json` 中 Cozy 对话短音登记为
  `licensed_for_game_use`；17 个 Balatro 文件仍为 `pending_unverified`。社区公开不构成
  授权，正式发行前仍需取得并记录明确许可。
- 对话与战斗页面新增展示信号，准确报告推进、选牌、取消和成功出牌；声音观察器不结算
  伤害或移动牌堆。自动检查和用户授权接入不能替代人工听感结论。

测试台所有候选可手动试听和绑定；环境声与暂未确认原用途的音效没有默认安排到常用动作。
来源及用途见[Balatro对照](Balatro音效对照与分类.md)，
待补用途与命名规则见[音效补齐清单](音效补齐清单.md)。
