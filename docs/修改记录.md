## 0.2.3-r1 按下立即瞄准

历史验收日期：2026-10-02。

原行为是点击卡牌后，必须松开鼠标才显示指向线。改为按下即选中和显示指向线，并支持按住拖到有效敌人后松开出牌。

- 保留先点选卡牌、再点击敌人的操作。
- 拖到空白处松开只保留选中，不消耗卡牌；再次点击选中牌、右键或 Esc 可取消。
- 用 `held_card_uid` 记录本次按住的牌；释放时重新检测目标。取消、进入忙碌状态或完成出牌会清理该状态，防止取消后误出牌及重复释放造成重复结算。
- 牌堆中的只读卡面不启用按下出牌行为。

主要位置：[card_view.gd](../scripts/combat/card_view.gd)、[battle.gd](../scripts/battle.gd)、[drag_visual.gd](../tests/drag_visual.gd)。

历史验证：拖动检查 11 项、原交互检查 16 项、牌堆检查 18 项，均为 0 失败。未调整战斗数值与存档格式。

## 0.2.2-r1 大界面牌堆浏览

历史验收日期：2026-10-02。

将抽牌堆和弃牌堆的文字弹窗替换为大尺寸完整卡面网格。

- 每行最多五张，卡面使用手牌模板的 1.2 倍尺寸；重复卡牌逐张保留。
- 超出区域时支持滚轮、触控板和垂直滚动条，可滚动到最后一张完整卡面。
- 展示时复制牌堆并按默认配置排序，同卡聚合；不改变实际抽取、弃置或洗牌顺序。
- 浏览界面拦截战斗操作和快捷键；Esc、右键、关闭或返回按钮退出。
- 同版本后续修正：卡面改为从最左侧开始排布，不足一行也不居中。这项修改未单独提升版本号。

主要位置：[pile_view.gd](../scripts/combat/pile_view.gd)、[card_view.gd](../scripts/combat/card_view.gd)、[battle.gd](../scripts/battle.gd)。

历史验证：牌堆检查 18 项、出牌交互检查 16 项，均为 0 失败。容量测试的 30 张卡只在测试内存中生成，没有加入正式牌组或用户存档。

## 0.2.1-r1 按钮与出牌表现

历史验收日期：2026-10-02。

统一按钮字体、文字居中、对称内边距、霓虹角标与悬停、按下、禁用反馈。按钮反馈不改变点击区域。

- 增加从选中卡牌连接鼠标的弧线和箭头；悬停有效敌人时变为洋红色并显示锁定环。
- 手牌悬停抬升、选中发光；出牌飞向目标，增加命中脉冲与伤害飘字。
- 将逐张等待抽牌改为错峰并行播放；命中后的弃牌动画和飘字不再阻塞下一次选牌。
- 非致命出牌起手锁定约 0.16 秒，命中后开放输入；致命命中保留短暂反馈后返回剧情。
- 飞行卡牌立即从可交互手牌字典移除，并关闭鼠标拦截，避免残影挡住后续点击。

主要位置：[ui.gd](../scripts/ui.gd)、[neon_button.gd](../scripts/widgets/neon_button.gd)、[battle.gd](../scripts/battle.gd)、[targeting_line.gd](../scripts/combat/targeting_line.gd)、[hit_fx.gd](../scripts/combat/hit_fx.gd)。

历史验证：剧情 690 项、战斗 191 项、交互 16 项及 R1 图形集成通过。交互曾在 1280×800 与 1600×1000 两种窗口尺寸验证。

## 0.2.0-r1 卡牌战斗初版

历史验收日期：2026-10-02。

根据《第一次修改清单》和更新后的实现文档，将战斗占位页改为可操作的临时卡牌战斗。

- 增加 `CombatModel`，分离战斗规则、视图、存档和剧情跳转。
- 临时规则为玩家 100 HP、单敌 3 HP、卡牌攻击 1、敌方意图攻击 1、三张手牌；可出牌、结束回合、洗回弃牌及判定胜负。
- 增加敌方下一行动显示、自然胜负及投降返回、演练入口、进出战斗花屏转场。
- 接入诺伦与机甲战斗立绘，区分对白图和战斗图；其他缺失敌图保留空位，姓名、HP、意图与点击目标仍可用。
- 增加共用 HP 和七天日期栏、医院与诊所恢复 30% 最大 HP、F1 调试入口和独立义体页。
- 冒险存档升级到 schemaVersion 2，支持旧版迁移及战斗快照；局外义体使用独立文件。
- 总览地图使用独立资源引用，未将港口背景冒充城市地图；总览插画与精确热点仍待提供。

历史验证：剧情 690 项、战斗 191 项，均为 0 失败；R1 图形集成 0 失败，并有实际鼠标操作记录。
