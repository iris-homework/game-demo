- 浮动详情替代原来的右侧常驻面板。悬停约 0.2 秒显示只读预览，点击固定单卡；已有固定卡时悬停其他地点只高亮，不替换固定卡。空白处或 Esc 关闭详情，周次弹窗存在时 Esc 先关闭弹窗。详情靠近窗口边缘会自动翻转或平移，不移动或缩放底图，也不改变锚点位置。任务类型文案为“主线任务”／“可选事件”，长标题与多事件列表可垂直滚动，底部“进入地点 →”与“治疗 · 回复 30% 最大 HP”按钮保持可用。

### 目标与流程

- `Game` 新增 `map_target_events()` 与 `map_place_state()`，用同一套条件求值统一过滤事件条件和地点条件；目标按事件 ID 稳定排序，多条可推进主线全部标金色，不任意选择其中一条。
- `state.targetId` 仍是已实现的委托对象字段（理查德／卢米娜），`activeEventId` 可能停留在上一次事件，二者都不作为地图目的地来源。
- 进入地点、开始事件与治疗仍调用原有 `Game.visit()`、`start_event()`、`heal_at()`，地图视图只负责展示与派发。`heal_at()` 不修改 `currentPlaceId`；治疗引起的视图重建通过 `pending_selection_id` 恢复所选详情。从地点返回地图时从干净总览开始。

### 纹理与着色器

- [map_assets.gd](../scripts/map/map_assets.gd) 通过 `ResourceLoader` 读取已导入纹理，导出包同样可用，不读取 PNG 源文件。符号在导入纹理的像素副本上按 alpha 主体裁切，超过 128 像素时降采样并生成 mipmaps，结果缓存在静态字典里复用；原始素材不做任何改写，也不使用图集。
- 外框状态由 [frame_state.gdshader](../scripts/map/frame_state.gdshader) 染亮边区分默认、青色悬停与浅色选中；当前位置头像的头肩裁切由 [map_assets.gd](../scripts/map/map_assets.gd) 在像素副本上完成，[round_avatar.gdshader](../scripts/map/round_avatar.gdshader) 只负责圆形遮罩与边缘处理。
