# 城市地图概念稿

本稿依据用户于 2026-10-04（Asia/Shanghai）补充的十二区域位置设计。
编号参考图仅用于空间关系；画风参考《欺诈之地》地图背景。
本稿记录插画设计阶段，基线为 0.2.3-r1。随后在 **0.2.4-r1** 接入了
`assets/map/map.jpg` 与 16 地点标记，见[地图界面验收清单](地图界面验收清单.md)。
下文“本轮”指当时概念稿制作，设计名称与游戏数据的区别仍保留。

## 画风与城市结构

地图采用斜俯视的手绘漫画背景：深色轮廓、块面阴影、低饱和灰紫与灰绿、
少量青色和洋红灯光。保持地标轮廓可辨，普通建筑细节弱于主要地标。

城市位于山地与海岸悬崖之间，右侧及右下为海洋。
街区沿多层台地连续展开，普通住宅、办公室、小商业楼、仓库、
道路、高架、桥梁、轨道、绿地与地形承担区域过渡。
区域不分割为独立主题岛，也不以大片空地分隔。

## 地理关系与画面信息

空间关系必须遵循用户的最新要求。

- 左侧自上而下为营地、垃圾场、后巷、蜂巢城寨。
- 沃斯大楼位于中央偏上；白昼庭院位于其右上高地。
- 义体教会位于沃斯大楼下方及五号街区左下。
- 五号街区承接企业核心与沿海工业区。
- 发电厂、黑潮泵站和港口沿右侧海岸自上而下连续分布。
- 末班车旅馆与蜂巢城寨、义体教会和旧铁路连接。

底图不绘制编号、红圈、地点名称、任务标识、HUD 或详情面板。
酒杯、床铺、医疗十字及义体圣像是建筑元素，可以保留。
本稿不展示地图行走人物。

## 设计与运行时的边界

用户最新设计优先于旧地点清单，但设计稿不自动改变游戏数据。

现有地点数据仍使用“革命军营地”，尚未新增“义体教会”。
本轮不修改地点 ID、解锁条件、治疗、事件、存档或地图热点。
黑市和地下诊所等现有地点没有因此删除；本轮按十二个主要区域设计，
它们未来可作为街区内的细分地点。

概念稿阶段未配置到 `cityMapAssetId`。0.2.4-r1 已将选定的 `map.jpg` 接入并
校准 16 地点；概念稿图片自身仍不替代 Godot 渲染与输入验收证据。
